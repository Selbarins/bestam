# Design

## Mood
Calm power + clarity. Deep dark, frosted glass, large confident numbers, restrained motion. OLED-friendly.

## Colors (HSL)
- Background: `0 0% 4%`
- Card: `0 0% 7%`
- Primary (accent): `38 92% 50%` (warm amber for now)
- Muted foreground: `40 10% 60%`
- Border: `0 0% 15%`

## Typography
System UI / Geist. Large numbers are the star.

## Components language
- Glass cards
- Progress rings / fluid bars
- Bottom navigation
- Minimal chrome
