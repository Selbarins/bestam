# Features

## Live now
- **Login-only auth** – single user, proxy protects all app routes
- **Dashboard** – live current balance (received income − actual expenses)
- **Fast expense capture** – amount → category → save
- **Add income** – amount + label + “mark as received”
- **Categories** – seeded defaults (Essentials / Lifestyle / Growth / Other)
- **Bottom navigation** – Home · Money · Goals · Insights · Settings
- **Logout** – in Settings
