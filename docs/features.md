# Features

## Signature
1. **Safe-to-Spend** – single hero number + fluid ring
2. **Fast capture** – amount → category → done
3. **What-if simulator**
4. **Weekly AI review**

## Core
- Income (primary + others, “Received” button)
- Expenses (planned vs actual, categories)
- Shopping cart (planned items reduce Safe-to-Spend)
- Recurring items
- Goals (Savings, Emergency Fund, Spending Cap first)
- Insights
- Currency: MAD default (store amount + currency + optional rate)

## Deliberately not included (for now)
Multi-user, bank sync, receipt photos, cart templates, heavy export
